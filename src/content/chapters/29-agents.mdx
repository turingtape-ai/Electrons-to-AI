Let the model's output be an action, run the action, and feed the result back in. This chapter describes that loop, the tools models are given, how plans form and break, and where the failure modes live. It connects back to Chapter 8: a machine that reads, acts, and moves to the next step.

The interactive will step through an agent loop one turn at a time.
