Chappe's towers sent numbers that pointed into a book. A processor reads numbers from memory and treats some as commands and some as data, according to an agreement baked into its wiring. This chapter makes that agreement concrete with a very small invented machine and a handful of instructions.

The interactive will be that machine, running programs you can edit.
