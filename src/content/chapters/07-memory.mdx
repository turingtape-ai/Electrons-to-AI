Everything so far forgets the moment the input changes. This chapter introduces a loop: two gates that each listen to the other, so that once set they stay set. One bit, remembered. Then rows of them, and a way of naming each row so a machine can ask for the one it wants.

The interactive will let you set and reset a single latch, then store and read back a short row of bits.
